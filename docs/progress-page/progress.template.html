구현된 기능

백엔드 API 27개

  • 시술 메뉴POST·GET·PUT /api/menus · POST /{id}/deactivate·activate삭제 대신 판매 중지해서 과거 매출을 보존
  • 고객POST · GET(검색) · GET /{id} · PUT /api/customers이름+번호 조합 중복 불가, 번호는 숫자만 저장, 문자 수신 동의 기본값 거부
  • 예약POST · GET(기간) · GET /{id} · PATCH /{id}/time · POST /{id}/cancel·complete·no-show겹치는 시간은 DB 제약(EXCLUDE)이 최종으로 차단
  • 매출POST · GET(기간) · GET /summary · GET /{id} · PUT /api/sales결제하면 예약이 자동 완료, 예약당 1건, 메뉴 이름·정가를 결제 시점으로 복사
  • 통계GET /api/stats/sales/daily·monthly·by-menu · /customers · /reservations실시간 집계, 서울 날짜 기준, 신규/재방문·노쇼율 정의를 ADR에 명시

앱 화면 (하단 탭: 홈 · 일정 · 통계 · 메뉴)

  • 홈오늘 요약, 오늘·이번 달 매출, 처리 안 된 지난 예약 알림, 다음 예약(남은 시간), 빠른 실행 6칸
  • 일정날짜별 예약을 시간순으로, 상태별 색 구분, 날짜 이동과 달력 선택
  • 예약 등록고객 검색·신규 등록, 메뉴 선택(종료 시각 미리보기), 날짜·시간, 서버의 겹침 메시지 표시
  • 예약 상세결제(정가 기본값과 할인액 표시), 시간 변경, 취소, 노쇼
  • 통계월 이동, 요약과 전월 대비, 일별 막대 그래프, 결제수단 비중, 메뉴 순위, 고객·예약 현황
  • 시술 메뉴목록, 등록·수정 폼, 판매 중지와 재개

품질

테스트가 잡은 문제들

  • 해결예약 시간 변경 시 엔티티를 먼저 바꾸면 조회 직전 자동 flush로 DB 제약이 먼저 터짐. 변경 전에 겹침을 확인하도록 순서 수정
  • 해결Dart 레코드 .wait가 에러를 감싸서 서버 메시지가 사라짐. Future.wait 목록 방식으로 교체
  • 해결Dart List.sort가 같은 값의 순서를 보장하지 않음. 비교 기준에 원래 번호를 추가
  • 해결가로 막대가 화면에 안 보임. 내용 없는 위젯은 Row 기본 정렬에서 높이가 0. 너비만 재던 테스트가 놓침
  • 해결빠른 실행 칸 글자가 폰 폭에서 잘림. 높이를 폭 비율에서 고정값으로 변경

교훈: 시각 위젯은 폰 폭(375px)으로 직접 열어 눈으로 확인합니다.

알려진 이슈와 위험

  • 출시 전 필수한글 글꼴 Flutter 웹이 한글 대체 폰트를 외부에서 내려받아 느린 네트워크에서 일부 글자가 □로 보일 수 있음대응: 한글 폰트를 앱에 포함
  • 개발 중 불편샘플 데이터 날짜 넣은 날 기준 상대 날짜라 며칠 지나면 앞으로의 예약이 줄어듦대응: 개발 DB를 비우고 다시 시작(전체 삭제 주의)
  • 정리 필요중복 코드 오류 화면이 홈·일정·메뉴·통계에 복사돼 있음대응: 공용 위젯으로 정리(P1)
  • 미확인접근성·다크 모드 통계 위젯의 스크린 리더와 다크 모드를 아직 점검하지 않음
  • 기능 공백환불·정정 이력 매출은 정정만 가능하고 이력과 환불이 없음대응: 백엔드 로드맵(P2)
