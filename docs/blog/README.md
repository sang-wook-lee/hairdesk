## 네이버 블로그에 올리는 방법

**자동 게시는 불가능합니다.** 네이버의 글쓰기 API는 2020년에 종료되었다고 보도되었고([뉴스핌 기사](https://newspim.com/news/view/20200413000737)), 외부 프로그램이나 자동화 도구로 블로그에 올리는 방법은 공식적으로 지원되지 않습니다. 직접 올려야 합니다.

1. 네이버 블로그 글쓰기 화면을 엽니다.
2. 마크다운은 **자동 변환되지 않는다**고 보는 것이 안전합니다. 글 내용을 붙여 넣은 뒤 제목·표·구분선 같은 서식은 에디터의 기능으로 다시 지정합니다.
3. 코드(SQL 등)는 서식이 깨지기 쉬우니 짧게 유지하거나, 에디터의 인용구·서식 기능을 쓰거나, 캡처 이미지로 넣는 것도 방법입니다.
4. 이미지는 `images/` 폴더의 파일을 **에디터에서 직접 업로드**합니다. (파일명이 번호순이라 글에 나오는 순서와 대응합니다)
5. 발행 전 "미리보기"로 휴대폰 화면 기준 서식을 확인합니다.

> 마크다운을 그대로 쓸 수 있는 곳(예: velog, GitHub 블로그)에는 이 `.md` 파일을 거의 그대로 올릴 수 있습니다. 이미지 경로만 해당 서비스에 맞게 바꾸면 됩니다.
